# Flow-JEPA reproduction

Reproduction setup and four-environment Slurm launch scripts for the upstream Flow-JEPA implementation.

The training implementation is maintained in [HuoYanchen/Flow-JEPA](https://github.com/HuoYanchen/Flow-JEPA), pinned to revision `ab73e7c50435e3a1fffb4d3f6d175445e57a2f4e`. These files contain the environment pins, public data and checkpoint download scripts, and a generic four-GPU launcher. See [`reproduction/README.md`](reproduction/README.md) for setup and paper parameter mapping.
